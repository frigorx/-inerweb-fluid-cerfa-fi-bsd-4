# Kit de présentation inerWeb Fluide

Ce dossier contient la page web de découverte d'inerWeb Fluide.

- `index.html` : page web interactive à publier avec le dépôt ; elle donne un accès direct à la démonstration, au guide, au courriel et à la demande de version locale.
- `styles.css` : mise en page responsive et version imprimable sur deux pages A4.
- `lisibilite.js` : réglage local de taille du texte, sans dépendance externe.
- `SOURCES-IMAGES.md` : traçabilité du visuel utilisé.

La version PDF envoyable est générée dans `output/pdf/inerWeb-Fluide-presentation.pdf`.

La page ne modifie ni la démonstration ni le logiciel. Le ZIP local n'est pas publié anonymement : le bouton prépare la demande de téléchargement nominatif.
