2Un fluide classé A2L est :

  1. ALégèrement inflammable, faible toxicité
  2. BTrès inflammable, faible toxicité
  3. CLégèrement inflammable, toxicité élevée
  4. DNon inflammable, non toxique

Légèrement inflammable, faible toxicité — A = faible toxicité, 2L = légèrement inflammable (vitesse de flamme < 10 cm/s). Ex: R32, R1234yf.

3La vitesse de flamme maximale pour un fluide classé A2L est de :

  1. A1 cm/s
  2. B5 cm/s
  3. C10 cm/s
  4. D30 cm/s

10 cm/s — Le 'L' de A2L signifie 'Lower flammability' : vitesse de flamme < 10 cm/s. C'est le seuil de la sous-classe 2L.

4La norme EN 378 classe les locaux en :

  1. A2 catégories, selon la charge admise
  2. B3 catégories (a, b, c) selon l'occupation
  3. C5 catégories, selon la classe du fluide
  4. D10 catégories, selon le type de bâtiment occupé

3 catégories — Catégorie a = accès public général. b = accès restreint. c = personnel autorisé uniquement. La charge maximale dépend de la catégorie.
