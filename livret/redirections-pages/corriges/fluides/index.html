1Dans la nomenclature Rxyz, le chiffre des dizaines (y) correspond à :

  1. ALe nombre d'atomes de chlore
  2. BLe nombre d'atomes de carbone moins 1
  3. CNombre d'atomes d'hydrogène + 1
  4. DLe nombre total d'atomes de fluor

H + 1 (atomes d'hydrogène + 1) — Règle de nomenclature : centaines = C−1, dizaines = H+1, unités = F. Ex: R134a → C=1+1=2, H=3−1=2, F=4.

2Le R410A est un mélange de :

  1. AR32 + R134a

R32 + R125 — Le R410A est un mélange quasi-azéotrope de R32 (50%) + R125 (50%). Ses hautes pressions le distinguent.
