Premier démarrage, pas à pas

Rien à installer · aucune compétence technique nécessaire · 5 minutes

1

Extraire le fichier reçu

Faites un clic droit sur le fichier inerWeb-Fluide-EVAL-….zip, choisissez « Extraire tout… » puis « Extraire ». Un dossier du même nom apparaît.

⚠️ Cette étape est indispensable : un double-clic dans le ZIP sans l'extraire ne peut pas fonctionner — le logiciel vous le dirait d'ailleurs lui-même.
2

Lancer le logiciel

Ouvrez le dossier extrait et double-cliquez sur lancer-inerweb.bat. Une fenêtre noire s'ouvre (c'est le moteur : laissez-la ouverte), puis votre navigateur affiche le logiciel.

Envie d'un accès direct ? Double-cliquez une fois sur creer-raccourci-bureau.bat : un raccourci « inerWeb Fluide » apparaît sur votre Bureau.

3

Si Windows affiche un avertissement bleu

Au tout premier lancement, Windows peut se méfier d'un programme qu'il ne connaît pas encore. C'est normal pour un logiciel remis directement, hors des magasins d'applications. Deux clics suffisent :

Windows a protégé votre ordinateur
Microsoft Defender SmartScreen a empêché le démarrage d'une application non reconnue…
① cliquez sur Informations complémentaires
② puis sur Exécuter quand même
4

Créer votre compte et entrer

À l'écran « Créer le compte administrateur », choisissez un identifiant et un mot de passe d'au moins 10 caractères — notez-les. Vous entrez directement dans le logiciel : le tableau de bord vous guide pour les premières étapes.

🔒 Tout reste sur votre ordinateur. Aucune donnée ne part sur internet : pas de compte en ligne, pas d'envoi, pas d'abonnement. Votre licence (à votre nom, fichier licence-inerweb.json) est vérifiée sur place.
